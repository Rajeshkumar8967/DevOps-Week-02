## Git Workflow

1. Create a GitHub repository.
2. Clone the repository.
3. Create or modify project files.
4. Stage the changes.
5. Commit the changes.
6. Push the changes to GitHub.
7. Create a branch.
8. Make changes in the branch.
9. Merge the branch into the main branch.
10. Resolve merge conflict in the code while merges

## Git Commands Used

```bash
git clone <repository-url>
git status
git add .
git commit -m "Initial Commit"
git push origin main
git branch feature-1
git branch feature-2
git checkout feature-1
git checkout feature-2
git checkout main
git merge feature-1
git merge feature-2
```
